# Application screenshots

Add **real screenshots captured from the validated v1.0.0 macOS build** here. Do not substitute mockups for screenshots.

Recommended names (PNG):

- `dashboard.png`
- `mac-health.png`
- `battery-health.png`
- `storage.png`
- `mac-details.png`
- `device-management.png` (if shown in the app)

Capture at a consistent window size, ideally in light and dark mode. Remove usernames, serial numbers, device identifiers, corporate details, and other personal information before committing.

After adding the files, uncomment the screenshot section in the repository README.
