# GitHub visuals

- `assets/app-icon.png` — repository README icon, derived from the existing validated Alpha 2 application icon.
- `assets/social-preview.png` — 1280×640 repository social preview card, created using the existing application icon.
- `assets/screenshots/` — reserved for **actual** macOS screenshots; none have been invented or included.

## Configure the social preview

In GitHub, open repository **Settings → General → Social preview → Edit**, and upload `docs/assets/social-preview.png`.

## Add screenshots

Capture the validated app on macOS and follow `assets/screenshots/README.md`. Commit the screenshots, then uncomment their Markdown references in `README.md`.

No application source, build scripts, or runtime resources were changed in this update.
