# Contributing

This project is in prerelease preparation and **is not yet cleared for public contributions or redistribution**. Once publication is authorized, propose changes through issues and small pull requests. Do not submit credentials, employee/device identifiers, internal URLs, or proprietary assets. Run `zsh Scripts/validate_on_mac.zsh` on macOS and include reproduction steps for bug reports. Do not alter the frozen Alpha 2 baseline; functional changes should branch to a subsequent alpha.
